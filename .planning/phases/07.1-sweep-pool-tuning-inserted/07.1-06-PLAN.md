<objective>
Run the one authoritative D-17 baseline measurement for this phase's completed work, and record what
it says, whichever way it says it.

This is the plan where the phase closes or escalates. It does neither speculatively: every figure it
records is transcribed from a downloaded CI artifact whose environment block reads
`hardwareConcurrency: 4`, and every disposition it writes names the figure that decided it.

**Both outcomes are planned for, because only one of them is knowable in advance: neither.** The
headline row started this phase at 1168.59ms normalized against a 1000ms budget. Plan 07.1-04's
worker-count decision is the phase's largest single lever and, at ideal linear scaling from three
workers to four, is worth roughly a quarter of that figure, which lands near 876ms. That is inside
budget and outside the 870ms margin target this phase declared in plan 07.1-01, by a hair. Real
scaling is rarely ideal. So the plausible outcomes are a comfortable pass, a thin pass, and a miss,
and this plan handles all three with the same discipline: record the figure, state the disposition,
name the lever for whatever did not close.

**The levers that remain if the headline still misses, named here so the escalation does not have to
invent one under pressure:**

  1. `runBacktest` writes three per-bar output arrays on every bar of every cell. The sweep worker
     reads back only the scalars on the returned result, plus a single final value on the IRR
     branch; the per-bar arrays are write-only scratch it never reads. Across roughly 247 million
     bar updates per full sweep, that is three array stores per bar that the sweep never consumes. A
     caller-selectable output-free mode would be answer-preserving by construction. This is
     reasoned from reading `src/kernel/backtest.ts`, not measured, and it is a kernel change rather
     than pool tuning, so it needs its own measurement and its own Key Decision.
  2. D-03's coarser default grid, still unspent and still in reserve. Spending it forfeits exactly
     what D-03 reserved it to preserve: the headline figure continuing to describe a fixed 200 x 50
     default view rather than a configuration-dependent one, and therefore continuing to be
     comparable across phases.

Purpose: one measurement, honestly recorded, with every criterion's disposition traceable to it.
Output: a transcribed baseline record, the Key Decisions this phase owes, and a ROADMAP whose
success criteria say what is true.
</objective>
