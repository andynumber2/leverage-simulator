`src/kernel/backtest.types.ts` exports:

- `KernelSeries` — `{ returns: Float64Array; shortRate: Float64Array; calendarDaysElapsed: Int32Array; contributionFlags: Uint8Array }`. Every array has the same length as the run window; index 0 is the entry bar.
- `KernelParams` — `{ leverage: number; initialInvestment: number; contributionAmount: number; financingSpread: number; expenseRatio: number; longGapMinDays: number }`. `financingSpread` and `expenseRatio` are annualized FRACTIONS, never percentages (D-09).
- `KernelOutputs` — `{ outValue: Float64Array; outRuined: Uint8Array; outLongGap: Uint8Array }`, all caller-preallocated to the run-window length.
- `KernelResult` — `{ finalValue: number; ruined: boolean; ruinBarIndex: number; droppedContributionsTotal: number; totalContributed: number; longGapBarCount: number; barCount: number }`. `ruinBarIndex` is `-1` when the run never ruined.
- `LONG_GAP_FLAG_MIN_DAYS = 6` — the D-04 outsized-closure threshold, inclusive. Planner discretion, exercised: only the 1933 bank holiday (12 days) and the 2001 closure (7 days) clear it; ordinary 3-day and 4-day holiday weekends do not.
- `FINANCING_DAY_COUNT_BASIS = 360` and `EXPENSE_DAY_COUNT_BASIS = 365` — deliberately different, per D-01/D-02.

`src/kernel/backtest.ts` exports:

- `runBacktest(params: KernelParams, series: KernelSeries, outputs: KernelOutputs): KernelResult`

`src/data/kernel-inputs.ts` exports:

- `BacktestRequest` — `{ symbol: string; dividendReinvest: boolean; leverage: number; entryDate: string; holdingPeriodBars: number | null; initialInvestment: number; contributionAmount: number; contributionFrequency: 'none' | 'daily' | 'monthly' | 'quarterly' | 'yearly'; expenseRatioPercent: number; financingSpreadPercent: number }`. `holdingPeriodBars: null` means hold to the last fully-supported bar (D-29).
- `LoadedBundle` — the decoded manifest plus a map from asset filename to `{ buffer, header }`, plus the shared calendar `Int32Array`.
- `KernelInputs` — `{ params: KernelParams; series: KernelSeries; outputs: KernelOutputs; window: { entryIndex: number; barCount: number; firstDate: string; lastDate: string }; meta: { seriesId: string; bundleVersion: string; truncatedForRateCoverage: boolean } }`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI argv → `buildKernelInputs` | Operator-supplied symbol, dates, leverage and amounts cross into index arithmetic over typed arrays |
| on-disk `public/data/*.bin` → decoder | A stale or truncated cached asset crosses into `Float64Array` views |
| data layer → kernel | Already-validated typed arrays and scalars cross into an unchecked hot loop |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information disclosure | `runBacktest` typed-array indexing | medium | mitigate | Pre-loop length asserts on all six arrays (Task 2), so an out-of-range window throws instead of reading past a buffer end |
| T-03-02 | Tampering | `decodeHeader` on a cached asset | high | mitigate | `decodeHeader(buffer, BUNDLE_VERSION)` is called with the required expected-version argument on every asset at load, so a stale asset raises `BundleVersionMismatchError` rather than returning numbers that disagree with the manifest |
| T-03-03 | Tampering (result integrity) | `buildKernelInputs` parameter handling | high | mitigate | D-32: out-of-range entry date or holding period throws naming the offending value and the supported range; no silent clamp anywhere on the path |
