<objective>
The first browser application: a static Vite plus Solid build that fetches the committed data
bundle over HTTP, decodes it zero-copy into typed arrays through the same code path the Node tests
already exercise, runs the Phase 3 kernel on the main thread, and paints a log-scale equity curve
for the default landing run.

Purpose: this is the phase's tracer. It proves every layer the phase will touch, end to end,
before any expansion task is written: static build, browser byte source, the D-02 loader seam,
`buildKernelInputs`, `runBacktest`, metric derivation and a rendered chart. If the architecture is
wrong, it is wrong after one commit rather than after ten.

Output: a runnable static app, a node-free `src/data/kernel-inputs.ts`, three byte-source modules
sharing one assembly loop, and a browser regression test that runs under `npm run test:app`.

Task ordering note: Task 2 is a prerequisite seam extraction, not an expansion slice. The browser
cannot fetch a single byte before it exists, and it produces no user-facing capability of its own,
so it precedes the tracer without violating tracer-first ordering.
</objective>
