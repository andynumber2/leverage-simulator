# Phase 4 - UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none - hand-rolled Solid.js components |
| Icon library | none - hand-authored inline SVG (log/linear toggle, theme override, copy-link, ruin marker) |
| Font | system stacks only, no web fonts. UI text: `system-ui, -apple-system, "Segoe UI", sans-serif`. Numerics: `ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace` |

**Why no shadcn:** shadcn's registry, CLI and component output target React (Radix primitives, JSX). This project's stack is Solid.js (`.claude/CLAUDE.md` §Q3), which has no official shadcn support. The shadcn init gate does not apply to a non-React Vite project. Hand-rolled CSS custom properties is also the stack doc's own prescribed mechanism for theme-aware canvas repainting (Q2: "implement as CSS custom properties read at render time... uPlot reads CSS custom properties at render time and repaints on theme change"), so it is the natural mechanism for the DOM chrome too, not an extra decision.

**Why no web fonts:** APP-03 forbids runtime external API calls and DATA-08 requires full offline operation after first load. A CDN-hosted font (Google Fonts et al.) would need to be precached anyway, adding bytes and a licensing dependency for no visual requirement stated in CONTEXT.md. System stacks give the numeric-monospace requirement (D-18) for free.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding around inline source citations, gap between a control's label and its value |
| sm | 8px | Compact element spacing - between a control and its adjacent source-citation text, between metric rows |
| md | 16px | Default element spacing - between distinct controls in the parameter column, chart-to-metrics gap |
| lg | 24px | Section padding - inside the parameter column and result column outer padding |
| xl | 32px | Layout gaps - between the parameter column and the result column at desktop widths |
| 2xl | 48px | Not used within the single-run screen; reserved for future page-level sections (e.g. methodology page, Phase 5) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Icon-only touch targets (log/linear toggle, theme override, copy-link button) are 44×44px minimum hit area regardless of their visual icon size, for touch accessibility.
- The instrument-panel voice (D-18: "dense layout... tight spacing") means the parameter column defaults to `xs`/`sm` between related elements and reserves `md`/`lg` for separating distinct control groups (symbol+dividend mode / leverage / entry+holding / contributions / costs) and the two outer columns. Do not use `xl`+ inside the parameter column.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / prose | 14px | 400 | 1.5 |
| Label / inline annotation | 12px | 400 | 1.4 |
| Heading / section title | 14px | 600 | 1.2 |
| Metric value (secondary) | 16px | 600 | 1.2 |
| Metric value (headline) | 28px | 600 | 1.15 |

4 distinct sizes (12, 14, 16, 28px), 2 weights (400 regular, 600 semibold).

- **Metric value (secondary)** and **Metric value (headline)** render in the monospace numeric font stack, per D-18. All other roles render in the system sans stack.
- **Label / inline annotation** is also the size for the per-control source citations D-18 requires ("0.90% - ProShares UPRO prospectus"), rendered directly beside the control it annotates, never in a tooltip or disclosure.
- Chart axis tick labels (uPlot) use the Label size (12px) in the monospace stack, so axis numerics visually match the metric panel's numerics.
- Headline metric value (28px/600, monospace) is reserved for the one IRR slot (D-05) - no other element on this screen uses that size.

## Color

Theme follows `prefers-color-scheme` with a manual override control (D-19). Both palettes below are required; do not ship light-only or dark-only.

| Role | Light | Dark | Usage |
|------|-------|------|-------|
| Dominant (60%) | `#F5F6F7` | `#14161A` | Page background |
| Secondary (30%) | `#FFFFFF` / border `#E1E4E8` | `#1D2024` / border `#2B2F35` | Parameter column surface, result column surface, metric panel card |
| Text primary | `#1A1D21` | `#E7E9EC` | Body text, labels, metric values |
| Text muted | `#5B6169` | `#9AA0A8` | Inline source citations, secondary/qualified metric text (e.g. the CAGR qualifier, the IRR=CAGR note) |
| Accent (10%) | `#2E6BD6` | `#5B9BF0` | Equity curve line stroke, log/linear toggle active state, focus outlines, the Copy Link button |
| Destructive / ruin | `#C4341F` | `#E2604B` | Ruin banner, ruin terminator marker on the chart, validation-error text and the invalid-control border |

Accent reserved for: the equity-curve stroke (the chart is "the only saturated element" per D-18), the active state of the log-scale toggle, keyboard-focus outlines, and the Copy Link button. Nothing else in the interface is accent-colored - this is what keeps the chart the visual center of a dense, otherwise-muted layout.

Destructive/ruin reserved for: the ruin-state banner and its icon, the chart's ruin terminator marker, and inline validation-error copy (D-11/D-12 evictions, D-10 cross-field explanations that block a run). Ruin uses this color specifically so it reads as a categorically different outcome from the continuous chart color scale, per D-07 and VIZ-06's later heatmap requirement - this phase establishes the color that Phase 7 must reuse for heatmap ruin cells.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Copy link" - the one explicit action button in this phase (SHARE-01). There is no "Run" or "Submit" button: parameter changes compute live (D-03), so the sole user-initiated action is copying the permalink. |
| Secondary action | "Run to today" - appears only in hold-to-today mode (D-14), refreshes the frozen end date encoded in the current permalink to the actual current date. |
| Landing state | No traditional empty state. See "Default Landing Run" below - the app always shows a computed result, or an explanation of why it cannot (invalid params, D-11). |
| Empty state heading | Not applicable - there is no zero-data / "add your first item" state in this phase. The symbol list is always populated from the bundled manifest; the result area is always either a computed run or an inline explanation. |
| Loading state (cold load) | While the bundle fetches and decodes (PERF-08a/b budget), show: "Loading market data…" in Body style, muted text, no spinner-only blank pane - PITFALLS F4 concern about a silent stall. |
| Error state - single-field bound (D-12 eviction) | Names the cause and the actual bound, e.g. "NDX total return starts 1999-03-04 - entry date must be on or after that." Result area clears per D-11; only this line remains. |
| Error state - cross-field impossibility (D-10) | Explains rather than blocks: e.g. "Holding period runs past the last supported bar (2026-06-30). Showing results through that date." Rendered as a caveat line above the (still-computed) result, not a block. |
| Bundle version mismatch (D-15) | "This link was created against an older data bundle (v{old}). Results below use the current bundle (v{new}); the underlying data has changed since this link was made." |
| Ruin banner (D-07) | "Position ruined on {date} - value reached zero and stays there." Categorical, dated, sits above the (retained, subordinate) metrics. |
| IRR-equals-CAGR note (D-05) | Inline, muted, beside the headline when contributions are zero: "IRR equals CAGR for a single cash flow." |
| CAGR qualifier (METR-02) | Inline, muted, beside the secondary CAGR value when contributions are non-zero: "CAGR is misleading with contributions - see IRR above." |
| IRR undefined (D-08) | "IRR undefined for this cash-flow pattern." Printed in place of a number; never `NaN` or `Infinity` reaches the screen. |
| Destructive confirmation | None in this phase - there is no delete/reset/irreversible action. (Ruin is a simulation outcome, not a user action, and needs no confirmation.) |

### Default Landing Run

Resolves F-04 (landing state was undecided). The app computes and shows a real result on first load rather than an empty/blank state, using parameters chosen to be mechanically derived rather than curated - avoiding PITFALLS G3's "defaults look cherry-picked" failure mode:

| Parameter | Default | Why this value, not another |
|-----------|---------|------------------------------|
| Symbol | SPX (S&P 500) | Most familiar index; the symbol Phase 3's own validation tracer used |
| Dividend reinvest | On (total return) | Matches Phase 3 D-10's amended pairing - financing is priced against total return |
| Leverage | 3x | The multiple actually sold as a product (UPRO/TQQQ family); neither the trivial 1x nor an alarmist extreme |
| Entry date | Earliest date in SPX total-return's strict tier | Mechanically derived from manifest, not hand-picked - "all the data we have," not a chosen window |
| Holding mode | Hold-to-today | Open-ended, mechanically resolved; not a curated historical window |
| Initial investment | $10,000 | Round, legible figure |
| Recurring contribution | None | Simplest headline case; IRR/CAGR framing (D-05) is visible without a contribution schedule complicating first read |
| Expense ratio / financing spread | Sourced defaults (SIM-09) | Same values D-18 requires be labelled and cited inline |

Every value above is itself subject to D-18's inline source-citation requirement - the entry date's citation reads "earliest available, {symbol} strict tier," not left uncited just because it's a computed default.

## UI Considerations

State coverage from the shape-rooted UI consideration probe (`ui-consideration-probe.cjs`), run after checker approval over 10 described surfaces. **54 applicable, 54 resolved (46 explicit, 8 backstop), 0 unresolved.** Element kinds were authored rather than left to the prose classifier: the heuristic detected no kind at all for `RuinBanner` and missed `media` on the chart, `static-content` on the metrics panel and citations, and `interactive-control` on the date and cost controls.

Empty-state and error-state **copy** lives in `## Copywriting Contract` above; the rows below cover state *coverage* and reference that copy rather than restating it.

### E1 - SymbolControl

_Kinds: form, list-collection, interactive-control_

| Category | Verification | Resolution |
|----------|--------------|------------|
| empty | explicit | Never empty. The symbol list is read from the bundled manifest, which is compiled at build time and asserted non-empty by the Phase 2 round-trip test; a manifest that decodes to zero symbols is a load failure, routed to the error state, not an empty select. |
| loading | explicit | Symbol select renders disabled with the LoadingNotice copy 'Loading market data...' until the manifest decodes. No control in the parameter column is interactive before the manifest resolves. |
| error | explicit | Manifest or bundle fetch/decode failure replaces the whole result column with a named failure line and a retry affordance; parameter controls stay disabled. Offline-after-first-load (DATA-08) means the service worker serves the precached bundle, so this state is reachable only on a genuinely cold failed first load. |
| populated | explicit | The bundled universe is a fixed ~10-symbol list (SPX, NDX/QQQ, UPRO, TQQQ, SSO, QLD, VTI, EFA, EEM, TLT). A single native select with no search, no grouping, no virtualization. |
| partial | explicit | A symbol whose total-return series is absent for the selected dividend mode is not silently dropped: the dividend-reinvest toggle is disabled for that symbol with the reason stated inline, per D-18's cite-everything rule. |
| overflow | 🧪 backstop | Longest bundled symbol label must not force the fixed-width parameter column wider; verify visually at the narrowest supported width. |
| zero-one-many | explicit | Not variable: the symbol count is fixed by the compiled bundle, so there is no zero/one/many layout variance. Adding a symbol is a recompile, and the select's layout is unchanged by count. |
| long-text | 🧪 backstop | Symbol label plus its inline source citation is the longest string in the parameter column; verify it wraps rather than clips. |

### E2 - LeverageControl

_Kinds: form, interactive-control_

| Category | Verification | Resolution |
|----------|--------------|------------|
| empty | explicit | Leverage has no empty state: it is always a number, defaulting to 3x (Default Landing Run). Clearing the numeric readout reverts to the last valid value rather than emptying, so the kernel is never called with NaN. |
| loading | explicit | Disabled with the rest of the parameter column until the manifest decodes. No independent loading state. |
| error | explicit | Out-of-range leverage (<=0 or >20x) is prevented at the control, not coerced: the slider bounds it and the numeric readout rejects the keystroke, with the bound named inline in destructive color per the D-12 eviction pattern. |
| partial | explicit | Mid-typing partial input in the numeric readout (e.g. '3.' or '-') does not trigger a run. Recompute fires on a parseable value only; the last valid result stays on screen until then. |
| long-text | explicit | Readout is a fixed-width monospace slot sized for the widest permitted value (two integer digits, two decimals, plus 'x'). Fractional leverage cannot widen the control. |

### E3 - EntryDateControl

_Kinds: form, interactive-control_

| Category | Verification | Resolution |
|----------|--------------|------------|
| empty | explicit | Entry date is never empty; it defaults to the earliest date in the selected symbol's strict tier and reverts to that on a cleared input. |
| loading | explicit | Disabled until the manifest decodes, because its valid bounds are derived from manifest tier ranges and cannot be known before then. |
| error | explicit | Out-of-tier dates use the D-12 eviction copy naming the actual bound ('NDX total return starts 1999-03-04 - entry date must be on or after that'), the result area clears per D-11, and the value is never silently coerced to the nearest valid date. |
| partial | explicit | A partially typed date does not recompute or evict. Validation runs on a complete, parseable date only. |
| long-text | explicit | Dates render in ISO YYYY-MM-DD in the monospace stack, a fixed 10-character width, locale-independent. No length variance. |

### E4 - HoldingModeControl + ContributionControl

_Kinds: form, interactive-control_

| Category | Verification | Resolution |
|----------|--------------|------------|
| empty | explicit | Contribution amount empty is a meaningful value, not a missing one: it means zero recurring contribution, which is the Default Landing Run. When it is zero the frequency selector is disabled and the CAGR qualifier is suppressed per D-05/METR-02. |
| loading | explicit | Disabled with the parameter column until the manifest decodes. |
| error | explicit | A fixed holding period running past the last supported bar uses the D-10 caveat-and-compute path: results still render, with 'Holding period runs past the last supported bar (YYYY-MM-DD). Showing results through that date' above them. Negative contribution amounts are rejected at the control. |
| partial | explicit | An amount with no frequency selected is impossible: frequency defaults to monthly the moment a non-zero amount is entered, and the default is labelled as a default per D-18. |
| long-text | explicit | Frequency options are a fixed closed set (none/daily/monthly/quarterly/yearly); amount is a monospace slot sized for a 9-digit figure. No variable-length text. |

### E5 - CostControls + SourceCitation

_Kinds: form, interactive-control, static-content_

| Category | Verification | Resolution |
|----------|--------------|------------|
| empty | explicit | Cost fields are never empty: clearing one restores the sourced default (SIM-09) and re-renders its citation, so a run is never computed against an unstated cost. |
| loading | explicit | Disabled with the parameter column; sourced defaults come from the compiled cost-parameter module, not from the bundle fetch, so they are known before decode completes. |
| error | explicit | Negative or non-numeric expense ratio / financing spread is rejected at the control with the bound named inline; the field never passes an unusable value to the kernel. |
| partial | explicit | A user-edited cost value drops the 'default' label and its citation is restated as 'user-supplied, sourced default was X' rather than removed, so a screenshot always shows what the number was compared against (CRED-05). |
| overflow | 🧪 backstop | Citation strings are the longest variable-length text in the dense parameter column; verify at the narrowest supported width that they wrap under their control rather than clipping or colliding. |
| long-text | 🧪 backstop | Longest sourced-citation string must wrap freely to whatever height its text needs without pushing the Copy link button below the fold. No line-count ceiling: an earlier draft of this row guessed "at most two lines", written before the real citation text existed. Measured at 320px the longest citation (`generic-3x-expense-ratio`) renders at roughly 8 lines, and every property that matters holds, no clipping, no collision, Copy link still above the fold. The two alternatives to accepting the height both cost more than they buy: shortening the string edits sourced text and breaks the SIM-09 audit trail, and a tooltip or disclosure contradicts SourceCitation's rule against concealing sourced text. Covered by `tests/app/narrow-viewport.browser.test.ts`. |

### E6 - EquityCurveChart

_Kinds: interactive-control, media_

| Category | Verification | Resolution |
|----------|--------------|------------|
| empty | explicit | A run with zero plottable bars cannot reach the chart: the D-11 clear-and-explain path replaces the chart with the validation explanation. The chart never renders an empty axis frame. |
| loading | explicit | Before first decode the chart area shows the LoadingNotice copy, not a blank canvas or a spinner alone (PITFALLS F4). Parameter-driven recomputes have no loading state: they are synchronous under the 16ms budget. |
| error | explicit | Log scale with a ruined position (values reaching zero) is the known failure: the curve terminates at the ruin marker in destructive color rather than plotting log(0). The toggle stays available and the ruin banner explains the truncation. |
| populated | explicit | Typical volume is ~25,000 daily bars over one series in a single uPlot canvas, accent stroke on the muted surface, axis ticks in the 12px monospace stack. This is the primary focal point of the screen. |
| long-text | 🧪 backstop | Y-axis tick labels grow with the value magnitude (a 3x run over 90 years reaches many digits); verify labels do not overrun the plot area at the widest formatted value in both linear and log mode. |

### E7 - MetricsPanel

_Kinds: list-collection, static-content_

| Category | Verification | Resolution |
|----------|--------------|------------|
| empty | explicit | The metrics panel is hidden entirely, not rendered with blank slots, whenever D-11 clears the result. Metrics and chart appear and disappear together. |
| loading | explicit | Hidden during cold load; the LoadingNotice occupies the result column. No skeleton placeholders, which would imply values that do not exist. |
| error | explicit | IRR that fails to converge or is undefined for the cash-flow pattern prints 'IRR undefined for this cash-flow pattern' in the headline slot (D-08). No NaN, Infinity, or '-' ever reaches the screen. |
| populated | explicit | Five rows: IRR headline (28px monospace), CAGR secondary with its qualifier, maximum drawdown, final value as a multiple of total contributed, and the dropped-contributions line (D-06). Row identity and order never change with the result. |
| partial | explicit | When contributions are zero, CAGR carries the 'IRR equals CAGR for a single cash flow' note and the dropped-contributions row is omitted rather than shown as zero. The headline slot is always IRR regardless (D-05). |
| overflow | 🧪 backstop | Extreme values (a 20x run over 90 years, or a near-zero final multiple) produce the widest metric strings; verify the 28px headline does not wrap or clip at the narrowest supported viewport, and that a wrapping secondary metric does not push the panel out of the D-20 screenshot region. |
| zero-one-many | explicit | The metric row set is fixed, not a variable-length list; only the dropped-contributions row is conditional. There is no plural-copy variance to handle. |
| long-text | explicit | Values are formatted before render: percentages to two decimals, multiples to two decimals with scientific notation above 1e6, so no metric string exceeds a bounded width regardless of the underlying number. |

| overflow | 🧪 backstop | The ruin date is the one fact this banner must always show; verify at the narrowest supported viewport that the banner wraps and never clips the date. |

### E9 - ValidationExplanation + BundleVersionBanner

_Kinds: form, static-content_

| Category | Verification | Resolution |
|----------|--------------|------------|
| empty | explicit | Absent by default. These elements render only when their condition holds; there is no placeholder or reserved empty slot, so the happy path has no residual chrome. |
| loading | explicit | The bundle-version mismatch check runs after the manifest decodes, so BundleVersionBanner can only appear once loading has finished. It never flashes during load. |
| error | explicit | These elements are themselves the error surface. Their three variants (single-field eviction, cross-field caveat, bundle mismatch) are specified verbatim in the Copywriting Contract above. |

### E10 - LoadingNotice + CopyLinkButton

_Kinds: interactive-control, static-content_

| Category | Verification | Resolution |
|----------|--------------|------------|
| loading | explicit | LoadingNotice is the cold-load state and must paint before PERF-08a's 1500ms interactive budget elapses. Copy link is disabled until a result exists, so there is no window where it copies a link to nothing. |
| error | explicit | A clipboard write rejection (permission denied, insecure context) is reported in place: the button label swaps to a failure state and the permalink is shown as selectable text as the fallback. A silent no-op is not acceptable for the phase's core action (SHARE-01). |
| overflow | explicit | The button label is fixed-width; the permalink itself is never rendered inline except in the clipboard-failure fallback, where it is a scrollable single-line monospace field. |

Rows marked 🧪 backstop are not under-specified by omission: each is a question that only a rendered pixel can answer (reflow, clipping, tick-label width at extreme values). Each must be discharged by a held-out visual UI-state check during execution, not asserted in prose.

## Layout & Component Reference

Supplementary to the template's required sections - captures D-17 through D-21's already-locked layout decisions in one place for the planner and executor. Not subject to checker sign-off (that covers the six dimensions above); still binding, since it comes directly from CONTEXT.md decisions.

### Visual hierarchy

**Primary focal point: the equity-curve chart** - the only accent-saturated element on an otherwise muted surface, occupying the largest area of the result column. Everything else is subordinate to it, in this order:

1. Equity-curve chart (accent stroke, largest area)
2. IRR headline metric (28px monospace, the only element at that size)
3. Ruin banner when present (destructive color; outranks the headline metric only in the ruin state, because it is a categorical outcome rather than a number)
4. Remaining metrics, then the parameter column, which is dense, muted, and deliberately recessive per D-18

No element other than those listed may compete for first read: adding a second saturated or oversized element to this screen breaks the contract.

### Screen structure (D-17, D-21)

```
Desktop (>= ~900px):
┌─────────────────────┬──────────────────────────────────────┐
│ Parameter column     │ Result column (slot)                  │
│ (fixed width,        │ - Phase 4: equity curve + metrics     │
│  persistent, scrolls │ - Phase 7 fills same slot w/ heatmap  │
│  independently)      │                                        │
│                       │ ┌──────────────────────────────────┐ │
│ Symbol + div. mode    │ │ Screenshot region (D-20):         │ │
```

### Component inventory (Solid.js, hand-rolled)

- `ParameterColumn` - container for all input controls, persistent and independently scrollable.
  - `SymbolControl` (select + dividend-reinvest toggle)
  - `LeverageControl` (scrubbable slider, rAF-coalesced per D-03, numeric readout in monospace)
  - `EntryDateControl` (date input, single-field bounds enforced live per D-10/D-12)
  - `HoldingModeControl` (fixed-period vs hold-to-today toggle; "Run to today" secondary action appears here in hold-to-today mode)
  - `ContributionControl` (amount + frequency)
  - `CostControls` (expense ratio, financing spread - both editable, both default-sourced and cited per D-18/CRED-05)
  - `SourceCitation` - the reusable inline annotation element every default-valued control renders beside itself (Label size, muted text)
  - `CopyLinkButton` - Primary CTA, accent-colored
- `ResultColumn` - the D-21 slot.
  - `EquityCurveChart` (uPlot, log/linear toggle, theme-aware repaint per D-19, ruin terminator marker)
  - `MetricsPanel` (IRR headline, CAGR secondary + qualifier, max drawdown, final-value multiple, dropped-contributions line per D-06)
  - `RuinBanner` (D-07 categorical state change, destructive color)
  - `ValidationExplanation` (D-11/D-12 clear-and-explain, D-10 caveat-and-compute)
  - `BundleVersionBanner` (D-15 mismatch notice)
  - `LoadingNotice` (cold-load state)

### Theme mechanics (D-19)

CSS custom properties for every color role above (`--color-bg`, `--color-surface`, `--color-text`, `--color-text-muted`, `--color-accent`, `--color-destructive`, plus border variants), swapped by a `data-theme` attribute driven by `prefers-color-scheme` and the manual override. uPlot and the hand-rolled canvas elements (Phase 6/7) read these same properties at render time and must repaint explicitly on theme change - canvas does not get free `prefers-color-scheme` styling.
