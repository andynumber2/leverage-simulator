<objective>
Build the third of the four competing forms (D-02 form 3): N stacked leverage strips, each a
one-dimensional entry-date band, rendering the same 10,000-cell field from the same committed
fixture, carrying the same legend and the same caveat, and measured against PERF-05.

Purpose: form 3 is the position that explicit separation between leverage rows reads better than
a continuous two-dimensional field. It is the only form that breaks the grid's vertical
continuity, so it is the only one that tests whether the entry-date axis is best read one leverage
at a time. It has to be built well enough to lose fairly.

Output: one mockup and one criterion-4 figure.
</objective>

  <action>
Export `FORM_3_GEOMETRY` as
`{ cols: 200, rows: 50, cellWidthPx: 4, stripHeightPx: 6, stripGapPx: 2, widthPx: 800, heightPx: 400 }`
and `paintSmallMultiples(ctx, fixture, metric)`. Fifty strips at 6px tall with a 2px gap gives
400px of canvas height, and 200 columns at 4px gives 800px of width, so the form renders every one
of the 10,000 cells (D-02's own requirement that each form render a full-scale field). D-12 gives
this form its own geometry, and a taller strip with a gap is exactly what distinguishes it from
form 1.

Paint each strip as its own one-dimensional band. Because the gaps mean the canvas is not a clean
integer upscale of the 200 by 50 field, do not use the whole-field `putImageData` path form 1 uses.
Instead build one reusable 200 by 1 `ImageData` row buffer, fill it from `valueToColor` for the
strip's leverage row, put it into a reusable 200 by 1 offscreen buffer canvas, and `drawImage` that
buffer stretched to `800 by 6` at the strip's y offset with `imageSmoothingEnabled = false`. That
is fifty `drawImage` calls per repaint rather than 10,000 `fillRect` calls, and it reuses the two
buffers across strips and across repaints so the measured figure reflects painting rather than
allocation. Allocate both buffers lazily on first use and never at module load, following
`bench/canvas-grid.ts`'s `getPutImageDataBuffer` precedent, because this module is also imported by
the `unit` project's typecheck where `document` does not exist.

Strip 0 is leverage 1.00x and sits at the BOTTOM of the canvas, column 0 is the earliest entry date
and sits at the LEFT, matching every other form (edge assumption A-E5). Fill the gaps with
`var(--color-surface)` read at paint time, so the separation reads as panel background in both
themes rather than as a colour on the scale (D-06).

Label every fifth strip with its leverage in `var(--font-mono)` at `var(--font-size-label)` in
`var(--color-text-muted)`, drawn in a left gutter reserved inside the 800px width, and draw the
same entry-year ticks along the bottom that form 1 draws. Overlay the ruin hatch on the union of
ruined cells with `makeHatchPattern` under a clip path (D-18), and leave incomplete cells flat and
untextured (D-20).

The HTML entry is a plain document with one module script calling `mountMockup` with the panel
title "Small multiples", the exact string `06-UI-SPEC.md`'s Copywriting Contract fixes, so the
caveat and the legend come from the shared runtime and are identical to every other form (D-23).

Prove paint equivalence before trusting any timing: clear the display canvas to a background
colour no `valueToColor` output can equal, assert the sample pixels read that background, run
`paintSmallMultiples` once, then assert each sample pixel at a strip's vertical centre equals
`valueToColor`'s own output for that cell's value and flags. Sample at least one cell in the first

colour rather than a scale colour, so the gaps are proven to be gaps.

Only then measure. Criterion 4 names a METRIC CHANGE, so the measured operation switches the metric
array from multiple-of-contributed to max drawdown and back, not a first paint. Use

an ordinary `expect` that the normalized figure is at or under
`PERF_BUDGETS['PERF-05'].thresholdMs`.

gated against 16ms and are not a ranking between forms, since D-12 has them painting at four
