    - `makeGridValues(seed)` returns a `Float64Array` of length `GRID_COLS` times `GRID_ROWS`, which is 10000, and two calls with the same seed are element-wise identical.
    - `mapValueToRgba(value)` is a pure function returning four integer channel values in the range 0 to 255 inclusive, deterministic for a given input.
    - `paintFillRect(ctx, values)` issues one `fillRect` per cell against a canvas sized `GRID_COLS` times the cell width by `GRID_ROWS` times the cell height.
    - `paintPutImageData(ctx, values)` writes one pixel per cell into a `GRID_COLS` by `GRID_ROWS` `ImageData`, applies it in a single `putImageData` call, then upscales it to the same display size with image smoothing disabled.
    - Neither paint function allocates a new `ImageData` or typed array per call after the first: buffers are created once and reused, so the measured figure reflects painting rather than allocation.
  </behavior>
