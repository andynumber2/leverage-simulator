## Autonomy note

This plan carries `autonomous: false` because of Task 2. `workflow.human_verify_mode` is `end-of-phase`, which normally routes human checks to a single end-of-phase pass, but a package-legitimacy gate is not an end-of-phase check: it must resolve **before** the install it guards, and the package-legitimacy protocol states such checkpoints are never auto-approvable regardless of `workflow.auto_advance`. Task 2 therefore stays a blocking human checkpoint positioned immediately before the only install this phase's fetch tooling might perform.

### Canonical output contract (D-03)

Every written CSV is exactly: the header line `date,value`, then one line per observation, `YYYY-MM-DD`, a comma, a finite decimal, LF line endings, a trailing newline, ascending dates, no duplicates, no blanks. FRED's `.` placeholder for a missing observation is dropped entirely rather than written as a blank or a zero, so the compiler sees a date gap and applies plan 02-02's carry-forward policy to it.

### Recorded licence position (D-05, D-06)

`sources.ts` carries `license` and `termsUrl` per source, authored once. FRED and Shiller are explicitly redistributable. Stooq's terms are permissive for personal use and unclear for redistribution; that is a knowingly accepted risk, not an oversight, and Task 3 promotes the reasoning to a Key Decision in `PROJECT.md` as D-06 requires.
