<objective>
Give the user the tier control the data layer has been ready for since Phase 2 (APP-02), and make
every consumer of the tier read one live value instead of a fixed one.

**User story (MVP):** **As a** user who wants to reach the pre-1954 era, **I want to** switch the
history tier and have the entry-date picker actually open up to that era, **so that** the tier
selector unlocks the history it claims to unlock instead of silently doing nothing.

Purpose: `bounds.ts` already carries both tier members and a tier-aware bounds resolver; Phase 4
deliberately pinned one value and left the removal to this phase.
Output: `TierControl.tsx`, an `activeTier()` state signal, and three call sites reading it.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query string -> tier selection | An existing permalink key now drives real behaviour instead of being written and ignored. |
| Manifest tier ranges -> entry-date bounds | The manifest decides which dates a tier admits; the control must not widen bounds beyond what the manifest carries. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-11 | Tampering | `tier` permalink value | low | mitigate | `decodeParams` already validates `tier` against its two-member set and rejects the whole permalink on an unknown value; this plan adds no new decode path and does not touch `permalink.ts`, asserted by a no-diff acceptance criterion. |
| T-05-12 | Tampering | Entry-date bounds widening | medium | mitigate | Bounds come only from `resolveEntryDateBounds` reading `manifest.series[].tiers[tier]`; the control never constructs a date bound itself, and an option whose tier range is absent renders disabled with the resolver's own reason. |
| T-05-13 | Repudiation | Citation naming a tier the bounds did not come from | medium | mitigate | The citation string interpolates the same `activeTier()` signal the bounds call uses, asserted by a browser test that reads the citation text after a tier change. |
| T-05-SC | Tampering | npm installs | low | accept | No package-manager install in this plan. |
</threat_model>
