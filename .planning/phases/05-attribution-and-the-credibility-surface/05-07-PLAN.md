<objective>
Ship the receipts (CRED-04): a full methodology page reachable in one click from any result,
generated from the code's own registries rather than written as prose about them.

**User story (MVP):** **As a** skeptic who wants to check an assumption, **I want to** open the
full cost model, day-count conventions, data sources and known limitations in one click without
losing the run I am looking at, **so that** I can inspect every assumption without leaving the
page.

Purpose: PITFALLS G1 — undisclosed methodology. D-18's generated-from-code approach exists so the
page is a rendering of what the model actually is, not a description of what the authors believe
it to be.
Output: `MethodologyOverlay.tsx`, the URL-flag plumbing, and the four limitation statements.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query string -> overlay flag | A new, non-allow-listed key is read from an untrusted URL before the strict permalink decoder runs. |
| Registry constants -> rendered methodology claims | The page's credibility rests on it rendering what the code actually is. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-17 | Tampering | Methodology flag read from `location.search` | medium | mitigate | The key is read by its literal name through an explicit `URLSearchParams.get` call and deleted from a copy before `decodeParams` runs. No dynamic property assignment from a URL-derived key occurs, matching `permalink.ts`'s existing stated discipline. `permalink.ts` is unmodified, asserted by a no-diff criterion, so the allow-list is neither widened nor weakened. |
| T-05-18 | Tampering / Information Disclosure | Flag masking an evicted run | medium | mitigate | The decode result still governs whether a run renders; a test asserts a flagged permalink with an invalid run produces the same eviction as the unflagged equivalent while also opening the overlay. |
| T-05-19 | Repudiation | Methodology prose drifting from the code | high | mitigate | Every value on the page is read from `COST_PARAMETERS`, `TOLERANCE_MECHANISMS`, the kernel day-count constants, the generated bias module or the manifest. Grep criteria forbid duplicate numeric literals, and a browser test compares rendered substrings against the imported constants. |
| T-05-20 | Tampering | Overlay URL write racing the run-parameter flush | low | mitigate | Overlay URL writes go through the same `history.replaceState` path and flush any pending trailing-edge write first; a test asserts open-then-close restores the exact original query string. |
| T-05-SC | Tampering | npm installs | low | accept | No package-manager install in this plan. |
</threat_model>
