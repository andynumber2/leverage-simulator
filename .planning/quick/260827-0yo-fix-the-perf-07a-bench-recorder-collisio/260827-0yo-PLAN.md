<objective>
Make a losing bench recorder degrade to an info line, in whichever file loses the race, and stop a
single rejected row from destroying an unrelated budget's measurement in the same file.

Purpose: CI run 33026990805 failed on an infrastructure crash, not a budget breach.
bench/perf-08-export.bench.test.ts guards its PERF-07a/production record attempt with a try/catch;
bench/perf-07.bench.test.ts does not, and its header comment's assumption that perf-07 always
claims the slot first is false because Vitest file execution order is not guaranteed. In that run
perf-08-export ran first, so perf-07 threw. Worse, perf-07 records its two rows in a loop, so the
PERF-07a throw aborted the loop before PERF-07b was ever attempted and PERF-07b came back
unmeasured despite owning an uncontested slot.

Output: one shared helper in bench/report.ts that attempts a record and reports whether it
persisted, both bench files rewired onto it, and unit tests proving degradation and per-row
isolation against the real EEXIST guard.

Explicitly NOT in scope: the two genuine budget breaches (PERF-07a at 128.69ms against 50ms and
PERF-03 at 1396.35ms against 1000ms). Success here is that those two are the only failures left,
rather than an infrastructure crash sitting on top of them.
</objective>
